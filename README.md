## Prerequisites

Node 20+
Yarn
It is required to set the environment variables or create `.env` file in order to run. There's a `sample.env` file in the project that shows an example.


## Installation

To install and set up the library, run:

```sh
$ git clone https://github.com/Sprimage/drylla
$ cd drylla
$ yarn install
```

Build and run drylla:

```
yarn
yarn build
yarn start
```
